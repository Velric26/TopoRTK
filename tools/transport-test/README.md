# Development-only host prototype

This earlier Python prototype is retained for reference. It is **not the field workflow** and its wire format differs from the ESP32 implementation. Do not connect it to the ESP32 diagnostic endpoint. Historical localhost artifacts in tests/2026-09-12-transport-test-kit/node0 and node1 only validate this host prototype, not radio or Wi-Fi hardware.

The supported no-PC field design runs on both ESP32 instruments and is operated from a tablet. See ../../docs/transport-field-test.md and firmware/um980-display-demo/src/link_diagnostic_core.h.
