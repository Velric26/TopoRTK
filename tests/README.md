# Test Records

Create one immutable directory per test run using:

```text
YYYY-MM-DD-short-test-name/
```

Copy `tests/_template/` to start a run. Complete its `README.md`, store exact device configurations under `config/`, and place raw observations and diagnostic output under `logs/`.

Do not overwrite a previous run. Repeat a test in a new dated directory and link both records from the relevant documentation.
